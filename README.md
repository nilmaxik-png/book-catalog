# Практическое занятие №5 — Менеджер задач

React-приложение для задач с дедлайнами. Работа находится в отдельной ветке `practice-5-tasks`.

## Установка и запуск

Нужны Git и Node.js версии 18 или выше. npm устанавливается вместе с Node.js.

```sh
git clone --branch practice-5-tasks --single-branch https://github.com/nilmaxik-png/book-catalog.git task-manager
cd task-manager
npm ci
npm start
```

Откройте http://localhost:3000.

`npm start` автоматически собирает приложение и запускает сервер. Для остановки нажмите Ctrl+C. После изменения исходников остановите сервер и снова выполните `npm start`.

## Возможности

- Добавление задачи с названием и дедлайном.
- Статусы `To Do`, `In Progress`, `Done`.
- Переключение статуса в строке задачи.
- Подсветка просроченных задач и текстовая отметка «Просрочена».
- Фильтр по статусу и количество показанных задач.
- Текущая местная дата браузера.
- Удаление задачи.

У новой задачи статус `To Do`. Название обязательно и содержит не более 120 символов. Можно добавить задачу с прошедшим дедлайном, чтобы проверить подсветку.

Дедлайн действует до конца выбранного дня. Сегодняшняя задача ещё не просрочена. Подсвечиваются задачи с дедлайном раньше текущей даты, если их статус не `Done`. Дата проверяется каждую минуту и при возвращении фокуса в окно.

Задачи хранятся в состоянии React. При перезагрузке страницы список сбрасывается.

## Структура проекта

- `src/index.html` — HTML-страница и контейнер для React.
- `src/style.css` — простое оформление и подсветка просрочки.
- `src/script.js` — компоненты, проверки, статусы и фильтрация.
- `tools/build.cjs` — сборка с помощью esbuild.
- `tools/server.cjs` — локальный сервер.
- `package.json` — зависимости и команды.
- `package-lock.json` — фиксированные версии зависимостей.

Основной код разделён на HTML, CSS и JavaScript.

Для отдельной сборки выполните `npm run build`. Результат появится в папке `dist`, которая не хранится в Git. В ней будут `index.html`, `style.css` и `script.js`.

## Проверка на защите

1. Клонируйте ветку `practice-5-tasks`, установите зависимости и запустите приложение.
2. Добавьте три задачи: со вчерашним, сегодняшним и завтрашним дедлайном.
3. Вчерашняя задача подсветится, сегодняшняя и завтрашняя — нет.
4. Переведите вчерашнюю задачу в `In Progress`: подсветка останется.
5. Переведите её в `Done`: подсветка исчезнет.
6. Выберите каждый статус в фильтре и затем «Все статусы».
7. Покажите текущую дату и историю коммитов на GitHub.

## Короткие ответы по коду

- `TaskForm` хранит поля через `useState`, проверяет ввод и передаёт новую задачу в `App` через props.
- `App` хранит массив задач и выбранный фильтр.
- `TaskList` выводит задачи с помощью `map`; уникальный `id` используется как React-ключ.
- При смене статуса `map` создаёт новый массив и обновляет только выбранную задачу.
- При удалении `filter` создаёт массив без задачи с нужным `id`.
- `visibleTasks` вычисляется из общего массива по выбранному статусу.
- `isOverdue` проверяет дедлайн и исключает задачи со статусом `Done`.
- Даты представлены в формате `YYYY-MM-DD`, поэтому их можно сравнивать как строки.
- `getToday` использует местную календарную дату, без смещения в UTC.
- `useToday` использует `useEffect` для таймера и обработчика фокуса; при размонтировании они удаляются.
- `React.createElement` позволяет создавать элементы без JSX в обычном файле `.js`.
