# Практическое занятие №4 — Учёт личных финансов

React-приложение для добавления доходов и расходов. Для этой работы используется ветка `practice-4-finance`; в ветке `main` находится практическая №3.

## Клонирование и запуск

Установите Git и Node.js версии 18 или выше. npm устанавливается вместе с Node.js.

```sh
git clone --branch practice-4-finance --single-branch https://github.com/nilmaxik-png/book-catalog.git personal-finance
cd personal-finance
npm ci
npm start
```

Откройте http://localhost:3000.

`npm start` автоматически собирает приложение и запускает сервер. Для остановки нажмите Ctrl+C. После изменения исходников остановите сервер и снова выполните `npm start`.

## Возможности

- Добавление операции: тип «Доход» или «Расход», категория и сумма.
- Список операций с типом, категорией и суммой.
- Общий доход, общий расход и баланс.
- Автоматическое сохранение операций в localStorage.
- Восстановление сохранённых операций при перезагрузке.
- Удаление операции с пересчётом итогов и обновлением хранилища.

Сумма должна быть положительной. Можно использовать точку или запятую, не более двух знаков после разделителя: `1250,50` или `1250.50`. Категория обязательна.

Деньги хранятся целым числом копеек, поэтому при сложении небольших дробных сумм не накапливается ошибка. Баланс рассчитывается как общий доход минус общий расход.

Данные сохраняются в браузере на текущем адресе. Для проверки восстановления обновите страницу после добавления операции. Если удалить данные сайта в браузере, история будет удалена. При ошибке чтения или сохранения приложение показывает сообщение.

## Структура

- `src/index.html` — HTML-страница с контейнером React.
- `src/style.css` — простое оформление.
- `src/script.js` — компоненты, проверки, расчёты и localStorage.
- `tools/build.cjs` — сборка проекта с помощью esbuild.
- `tools/server.cjs` — локальный сервер.
- `package.json` — зависимости и команды.
- `package-lock.json` — фиксированные версии зависимостей.

Основной код разделён на HTML, CSS и JavaScript. Для сборки отдельно можно выполнить `npm run build`. Результат появится в папке `dist`, которая не хранится в Git.

## Короткие ответы по коду

- `OperationForm` хранит значения полей через `useState`, проверяет ввод и передаёт данные в `App`.
- `App` хранит массив операций и передаёт данные и обработчики дочерним компонентам через props.
- `OperationsList` отображает операции через `map`, ключом служит уникальный `id`.
- `Totals` суммирует доходы и расходы, затем вычисляет баланс.
- `loadOperations` читает сохранённые данные при первом создании состояния.
- `useEffect` сохраняет изменившийся массив операций.
- localStorage хранит строки: `JSON.stringify` превращает объект в строку, `JSON.parse` восстанавливает объект.
- `useRef` позволяет пропустить запись при первом чтении хранилища.
- `React.createElement` создаёт элементы без JSX, поэтому исходник имеет расширение `.js`.
