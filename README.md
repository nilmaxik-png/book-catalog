# Практическое занятие №3 — Каталог книг

React-приложение с простым оформлением. Код страницы разделён на HTML, CSS и JavaScript.

## Быстрый просмотр

Откройте `dist/index.html` в браузере. В этой папке лежит готовая сборка с React; интернет для просмотра не нужен.

## Запуск проекта

Нужны Node.js версии 18 или выше и npm. В терминале в папке `book_catalog` выполните:

```sh
npm ci
npm run build
npm start
```

Откройте http://localhost:3000. Чтобы остановить сервер, нажмите Ctrl+C.

После изменения исходников снова выполните `npm run build` и обновите страницу. Команда `npm run dev` собирает проект и запускает сервер.

## Файлы

- `src/index.html` — HTML-страница с контейнером для React.
- `src/style.css` — простое оформление.
- `src/script.js` — данные книг, компоненты React, корзина и маршруты.
- `tools/build.cjs` — сборка с помощью esbuild.
- `tools/server.cjs` — локальный сервер.
- `package.json` и `package-lock.json` — команды и фиксированные версии зависимостей.
- `dist/` — готовая сборка с тремя файлами.
- `.git/` — локальная история разработки.

## Что реализовано

Каталог показывает название, автора и цену каждой книги. Кнопка добавляет одну книгу в корзину; повторное нажатие добавляет ещё один экземпляр. Корзина доступна по отдельному маршруту `#/cart`, каталог — по `#/catalog`. В корзине отображаются количество экземпляров и общая стоимость. Можно удалить один экземпляр или очистить всю корзину.

Состояние корзины хранится в `useState` компонента `App`: переход между страницами его сохраняет, перезагрузка страницы сбрасывает. Счётчик вычисляется через `cart.length`, сумма — через `reduce`.

## История Git и GitHub/GitLab

В архиве подготовлен локальный Git-репозиторий с отдельными коммитами по этапам разработки. Удалённый репозиторий GitHub/GitLab ещё не создан и не заполнен. По заданию работа должна быть размещена там, а на защите нужно показать историю и клонирование.

Посмотреть локальные коммиты:

```sh
git log --oneline --graph --all
```

Создайте пустой репозиторий `book-catalog` в своём аккаунте GitHub или GitLab без README, лицензии и .gitignore. Затем в папке проекта выполните команды, заменив адрес примером своего репозитория:

```sh
git remote add origin https://github.com/YOUR_LOGIN/book-catalog.git
git push -u origin main
```

Для GitLab используйте адрес своего репозитория GitLab. Эти команды отправят всю подготовленную историю. Загрузка файлов через веб-интерфейс не переносит локальные коммиты.

Для следующих коммитов можно задать свои имя и email:

```sh
git config user.name "Ваше имя"
git config user.email "Ваш email"
```

После загрузки продемонстрируйте клонирование в новую папку:

```sh
git clone https://github.com/YOUR_LOGIN/book-catalog.git book-catalog-demo
cd book-catalog-demo
npm ci
npm run build
npm start
```

Готовая папка `dist` исключена из Git: после клонирования она создаётся командой сборки.

## Если папка .git потерялась при распаковке

В корне ZIP дополнительно лежит `book_catalog.bundle` со всей историей. Из папки с этим файлом можно восстановить репозиторий:

```sh
git clone book_catalog.bundle restored_catalog
cd restored_catalog
npm ci
npm run build
npm start
```

Перед привязкой восстановленного проекта к GitHub замените локальный адрес bundle:

```sh
git remote set-url origin https://github.com/YOUR_LOGIN/book-catalog.git
git push -u origin main
```

## Что показать преподавателю

1. Клонирование репозитория с GitHub/GitLab и команды запуска.
2. Каталог: название, автор, цена и добавление нескольких книг.
3. Отдельную страницу корзины и изменение количества книг.
4. Историю коммитов на сайте GitHub/GitLab.

## Коротко о коде для защиты

- `Catalog` отображает массив книг через `map`, получает функцию добавления через props.
- `Cart` получает массив корзины и функции удаления/очистки через props.
- `App` хранит корзину, страницу и сообщение через `useState`.
- При добавлении используется новое значение массива: React замечает изменение и перерисовывает интерфейс.
- `useEffect` подписывается на `hashchange` и удаляет обработчик при размонтировании.
- `React.createElement` создаёт элементы без JSX, поэтому исходник имеет расширение `.js`.
