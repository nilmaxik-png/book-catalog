# Практическое занятие №7 — Карта дорожной обстановки

Приложение React Native / Expo показывает Москву. На карте есть цветные маркеры, карточки участков и кнопка «Обновить данные». Длина и время проезда поступают из российского внешнего API «Квазар» с включённым учётом пробок.

Работа находится в ветке `practice-7-traffic` репозитория `nilmaxik-png/book-catalog`.

## Обновление уже установленного проекта

В окне с предыдущим сервером нажмите Ctrl+C, затем выполните в Git Bash:

```sh
cd ~/book-catalog
git switch practice-7-traffic
git pull --ff-only origin practice-7-traffic
npm ci
npx expo start --clear
```

Полностью закройте предыдущее приложение в Expo Go и заново отсканируйте QR-код. Очистка кэша важна после замены компонента карты и зависимостей.

## Установка новой копии

Нужны Git, Node.js LTS и подключение к интернету.

```sh
git clone --branch practice-7-traffic --single-branch https://github.com/nilmaxik-png/book-catalog.git traffic-map
cd traffic-map
npm ci
npm start
```

Если репозиторий уже клонирован, но ветка ещё не открывалась: `git fetch origin`, затем `git switch practice-7-traffic`, `npm ci` и `npm start`.

### На телефоне

Проект использует Expo SDK 57. Для Android установите соответствующий клиент со [страницы Expo Go](https://expo.dev/go). Телефон и компьютер должны находиться в одной Wi-Fi-сети. Откройте Expo Go и отсканируйте QR-код терминала.

На iPhone/iPad проверьте [совместимость клиента и SDK](https://docs.expo.dev/troubleshooting/expo-go-version-mismatch/). Версия клиента из App Store может не подходить для SDK проекта.

Карта на телефоне работает через `react-native-webview` и Leaflet. Google Maps SDK и ключ Google Maps не используются. `react-native-webview` включён в совместимый Expo Go. Движок карты, стили и служебные изображения включены в приложение; для их загрузки не нужны внешние CDN.

Из интернета загружаются изображения OpenStreetMap и дорожные данные. Если изображения не загрузились, на карте появится сообщение с кнопкой повторной загрузки. Ошибка дорожного API показывается отдельно; при ней сама карта остаётся доступна.

### В браузере

В терминале Expo нажмите `w` в английской раскладке или выполните `npm run web`. Адрес показан в терминале, обычно http://localhost:8081.

Браузер использует тот же HTML и движок карты, что и мобильный WebView. Масштаб меняется кнопками +/−, колёсиком или жестом на телефоне. Карту можно перемещать.

## Внешний API и смысл показателей

- [Официальная документация российского API «Квазар»](https://api.1traffic.ru/v2/).
- Запрос: `POST https://api.1traffic.ru/v2/matrix?key=demo&traffic=1`.
- В JSON передаются начала и окончания восьми заранее выбранных коротких маршрутов в Москве.
- `traffic=1` включает учёт текущей дорожной обстановки при расчёте пути.
- Из матрицы выбираются только пары начала и конца одного участка. Длина пути и время проезда берутся из ответа, а средняя скорость вычисляется как `distance * 3600 / time`.
- Маркер установлен в середине между заданными точками. Названия маршрутов и их точки заданы в проекте; числовые показатели приходят из API.
- Рассчитанный путь может включать объезд и разворот. Оценка относится к маршруту между точками, а не ко всей одноимённой улице и не к отдельному дорожному датчику.
- API не возвращает время исходного дорожного измерения. Приложение показывает только время получения ответа в МСК и не придумывает метку времени датчика.

Ключ `demo` опубликован самим поставщиком для разработки и тестирования; отдельная регистрация для учебной демонстрации не нужна. У него общий лимит 1 запрос в секунду. Если сервис занят или ограничил запросы, приложение показывает ошибку. Для коммерческого использования нужен собственный доступ поставщика.

Запрос отправляется при открытии приложения и по кнопке обновления. На время запроса кнопка блокируется. При ошибке сохраняются предыдущие значения с прежним временем получения и сообщением, что данные не обновились. Время ожидания — 20 секунд. Случайной генерации и подмены данных при ошибках нет.

JSON передаётся с `Content-Type: text/plain;charset=UTF-8`: сервер принимает такой запрос и возвращает JSON с разрешённым CORS. Тип `application/json` вызывает неподдерживаемый этим API предварительный запрос OPTIONS в браузере.

### Цвета маркеров

Это учебная оценка средней скорости рассчитанного маршрута, а не официальный индекс пробок поставщика.

| Цвет | Состояние | Средняя скорость |
| --- | --- | --- |
| Зелёный | Свободно | От 40 км/ч |
| Жёлтый | Средняя загрузка | От 20 до 40 км/ч, не включая 40 |
| Красный | Пробка | Менее 20 км/ч |

Не обязательно все три цвета присутствуют одновременно: это зависит от текущего ответа API. В карточке показаны название участка, оценка состояния, средняя скорость, длина и время пути. После обновления открытая карточка использует новые значения.

## Структура

- `App.js` — экран, легенда, кнопка обновления и выбранный участок.
- `hooks/useTraffic.js` — загрузка, состояние, отмена и обработка ошибок.
- `services/trafficApi.js` — внешний запрос и тайм-аут.
- `domain/mapRegion.js` — Москва и точки восьми маршрутов.
- `domain/traffic.js` — проверка ответа, расчёт скорости и цвета.
- `components/TrafficMap.native.js` — мобильный WebView и обмен сообщениями с картой.
- `components/TrafficMap.web.js` — браузерная оболочка той же карты.
- `components/RoadDetails.js` — карточка участка.
- `map/runtime.js` — карта Leaflet, маркеры, выбор участка и ошибки загрузки изображений.
- `tools/build-map.cjs` — включает Leaflet и стили в локальный HTML.
- `map/mapDocument.js` — сгенерированный HTML, уже сохранён в репозитории. Пересоздаётся при `npm ci` и командой `npm run build:map`.
- `tests/` — проверки API, расчётов, ошибок и отмены запросов.

## Демонстрация и проверка

1. Откройте приложение и дождитесь карты Москвы и количества участков.
2. Покажите легенду и цветные маркеры.
3. Нажмите маркер: откроется карточка дороги.
4. Нажмите «Обновить данные»: кнопка временно блокируется, затем меняется время получения ответа.
5. Отключите интернет и повторите обновление: появится ошибка с сохранением прежних данных.
6. Покажите [историю коммитов](https://github.com/nilmaxik-png/book-catalog/commits/practice-7-traffic/).

```sh
git log --oneline --graph
npm test
npm run export:web
npm run export:android
```

Проверены 11 автоматических тестов, настоящий ответ российского API в браузере, загрузка OpenStreetMap, карточки, обновление и ошибки сети. Проверены экран шириной 390 пикселей и обмен сообщениями, который используется мобильным WebView.

Экспорт для веба и Android прошёл. Экспорт Android проверяет JavaScript/Hermes-бандл; он не создаёт установочный APK. Физический телефон или Android-эмулятор в среде подготовки не запускался.
