# Практическое занятие №3 — Каталог книг

React-приложение с простым оформлением. Каталог показывает название, автора и цену книги. Книги можно добавлять в корзину, смотреть их количество, удалять отдельные экземпляры и очищать корзину.

## Установка и запуск

Нужны Git и Node.js версии 18 или выше, вместе с которым устанавливается npm.

```sh
git clone https://github.com/nilmaxik-png/book-catalog.git
cd book-catalog
npm ci
npm start
```

Откройте http://localhost:3000.

Команда `npm start` сама собирает проект и запускает локальный сервер. Для остановки нажмите Ctrl+C. После изменения исходников остановите сервер и снова запустите `npm start`.

## Структура проекта

- `src/index.html` — HTML-страница и контейнер React.
- `src/style.css` — простое оформление.
- `src/script.js` — массив книг, React-компоненты и корзина.
- `tools/build.cjs` — сборка проекта с помощью esbuild.
- `tools/server.cjs` — локальный сервер.
- `package.json` — зависимости и команды.
- `package-lock.json` — фиксированные версии зависимостей.

Основной код разделён на HTML, CSS и JS. Дополнительные файлы нужны для установки и запуска React.

## Возможности

- Каталог из пяти книг с названием, автором и ценой.
- Кнопка «Добавить в корзину» у каждой книги.
- Отдельные маршруты `#/catalog` и `#/cart`.
- Количество книг в навигации и на странице корзины.
- Общая стоимость, удаление одной книги и очистка корзины.

Повторное добавление увеличивает количество экземпляров. Корзина сохраняется при переходах между страницами. При обновлении страницы она сбрасывается: данные хранятся в состоянии React.

## Отдельная сборка

```sh
npm run build
```

Появится папка `dist` с `index.html`, `style.css` и `script.js`. Её страницу можно открыть прямо в браузере. В Git эта папка не хранится: она создаётся при сборке.

## Кратко о коде для защиты

- `Catalog` отображает книги с помощью `map` и вызывает функцию добавления через props.
- `Cart` получает массив корзины и функции удаления/очистки через props.
- `App` хранит корзину и текущую страницу через `useState`.
- При добавлении создаётся новый массив: React замечает изменение и обновляет интерфейс.
- Количество вычисляется через `cart.length`, стоимость — через `reduce`.
- `useEffect` подключает обработчик `hashchange` и удаляет его при размонтировании.
- `React.createElement` создаёт элементы без JSX, поэтому исходный файл называется `script.js`.

Для защиты покажите клонирование, установку зависимостей, запуск, добавление нескольких книг, отдельную страницу корзины и историю коммитов на GitHub.
